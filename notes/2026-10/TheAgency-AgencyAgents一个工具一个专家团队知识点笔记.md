# TheAgency / AgencyAgents：一个工具=一个专家团队（知识点笔记）

## 一句话总结
`TheAgency`（GitHub ~158k 星，MIT，726 次提交）把"一整个公司的专家团队"打包成可按需调用的 AI 代理集合，配合原生应用 `AgencyAgents` 一键装进 Claude Code / Cursor / Codex / Gemini / Osaurus，一个人就能配齐"数字员工"干完一家公司的活。

## 核心要点
1. **本质**：每个代理是"拥有独特个性、流程和可靠成果的专业人士"——专业、个性驱动、注重成果、生产就绪。
2. **起源**：源自 Reddit 一个帖子，经数月迭代成精心打造的代理角色集合。
3. **一键安装**：`AgencyAgents` 是 macOS/Linux/Windows 原生应用（agencyagents.app），浏览代理名单后一键安装到各大编程工具，无需克隆/脚本，自动更新。
4. **组织结构（按"部门"划分代理）**，覆盖面极广：
   - 工程：前端/后端架构师、移动、AI 工程师、DevOps、网络、快速原型、高级开发、自主优化架构师…
   - 安全：安全架构师、应用安全、渗透测试、云安全、事件响应、威胁情报/检测、合规审计（SOC2/ISO/HIPAA/PCI）、区块链安全、AI 生成代码安全…
   - 产品/项目：冲刺优先级排序、趋势研究员、反馈合成器、产品经理、项目管理…
   - 付费媒体/销售：PPC 策略师、搜索词分析师、付费媒体审计、跟踪测量、广告创意、程序化展示、付费社交、外向型策略师、探索教练…
   - 数据/平台：数据整合、身份与信任架构、MCPBuilder、文档生成器、自动化治理…
   - 游戏：Unity 架构师、技术美术、游戏音频、叙事设计师、经济设计、Roblox…
   - 学术：人类学家、地理学家、历史学家、叙事学家、心理学家、统计学家、GIS…

## 展开说明
- **真实用例（视频演示）**：创业 MVP（前端+后端+增长+原型+现实检验）、多渠道营销活动、企业功能开发、付费媒体账户 30 天接管、全面代理产品探索（8 部门并行）、智慧校园数字孪生（BIM/GIS/无人机/WebGIS/3D）。
- **价值主张**："一个人干完一家公司的活"——用 all-in-one 的数字员工替代多岗位协作。
- **注意**：代理数量/部门随仓库迭代增加（OCR 中已见新增 GIS、DeepSeek 支持等），以仓库最新为准。
