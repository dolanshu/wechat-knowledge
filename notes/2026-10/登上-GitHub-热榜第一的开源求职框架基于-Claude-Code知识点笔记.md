# 登上 GitHub 热榜第一的开源求职框架（基于 Claude Code）知识点笔记

## 一句话总结
一个被裁的**地球物理学家**用 Claude Code 搭了套求职工作流并开源，**登 GitHub 热榜第一（2.9w+ star）**：他投 69 份简历、拿 20 个一面，最后转进 AI 工程。框架把简历、岗位分析、求职信、面试准备全做成 Claude Code 工作流，多维度评估匹配、双 Agent 互审、全链路追踪。

## 核心要点
- **故事**：作者被裁后靠这个开源项目杀回 AI 行业——从改简历到准备面试每一步拆开；69 份投递 / 20 个一面 / 入职 AI 工程师。
- **形态**：基于 Claude Code 构建，把简历、岗位分析、求职信、面试准备做成工作流；完全由你掌控。
- **能力**：从技能、经验、发展方向、岗位要求等多维度评估岗位匹配度；量身定制简历、撰写求职信、生成面试备考包；**双 Agent 互审**把控质量；全链路追踪求职进展。
- **痛点直击**：找工作最难不是发简历，是不知道岗位到底要什么。

## 展开说明
- 与 `015`（ai-job-search，21.3k star）是**不同的求职框架**，但思路高度一致（Claude Code + 多维度匹配 + 双 Agent 复核 + 面试准备），可对照看。
- **价值**：把"海投脏活"系统化，人只做最终决策（与 `015` 的"不无人值守自动投递"边界一致）。
