# RAG 文档切割策略（面试向）知识点笔记

> 来源：微信视频号《面试官问：RAG 系统中，常见的文档切割策略有哪些？》
> 提取方式：抽帧 → 画面 OCR → 整理
> 日期：2026-10-23

## 一句话总结
RAG 效果不好常卡在"切得不对"。文档切割按**文档类型**选策略，能背出这几种并说清适用场景，就是合格的工程答案。

## 核心要点（切割策略）
1. **固定长度切**：按字符 / Token 数切，带重叠（最朴素，易切断语义）。
2. **按分隔符切**：按标点、段落等自然边界切。
3. **结构感知切**（有标题 / 代码块 / 多级标题）：按函数、类的边界切 → 结构完整、上下文连贯、语义完整，每块是一个完整语义单元。
4. **语义驱动切**（无明显结构的长文档，如规章制度、研究报告）：计算相邻句子向量相似度，**相似度下降 = 话题切换**，在切换点下刀。
5. **进阶一 · 检索增强（小块索引、大块返回）**：索引用小颗粒保证命中精度，返回用大块保证上下文完整——小块索引 + 大块父块。
6. **进阶二 · 智能体驱动切**：让 LLM 自己读文档、自主决定切割点和方式；更灵活智能，但**成本较高**，需评估是否值得。

## 展开说明
- **原则**：看菜下刀——按文档类型升级策略；切多大、重叠多少，看**命中率和答案正确率**调。
- **面试要点**：能背出五种策略的名字 + 适用场景即可；能补充"小块索引/大块返回""智能体驱动"是加分项。
