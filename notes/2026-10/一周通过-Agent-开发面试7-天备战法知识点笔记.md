# 一周通过 Agent 开发面试（7 天备战法）知识点笔记

> 来源：微信视频号《一周时间，如何准备并通过 Agent 开发面试？》
> 提取方式：抽帧 → 画面 OCR → 整理
> 日期：2026-10-23

## 一句话总结
一套**功利但有效**的一周 Agent 开发面试备战法：前 2 天背高频题 → 3-4 天练 3 道真题 → 第 5 天包装项目 → 第 6 天模拟面试 → 第 7 天只补漏洞，最后按"八股/项目/代码/方案"四件事闭环。

## 核心要点（7 天计划）
- **DAY1-2 背高频题**：按模块（概念 / 流程 / 追问）拆开，别东看一点西学一点。
- **DAY3-4 练 3 道题**：每道题按 5 步讲——需求分析 → 技术方案 → 核心流程 → 异常处理 → 优化方向；**关上答案自己重新说一遍**（难的不是"看过"，是能继续往下讲）。
- **DAY5 项目重新包装**（最关键）：RAG 知识库问答系统"太单薄"，至少准备清 7 问——为什么做 / 整体架构 / Agent 负责什么 / 用了哪些工具 / 遇到什么问题 / 怎么定位 / 怎么优化；RAG 召回不准要能答 6 连问（分块太大？Query 改写？Top-K 合理？加 Rerank？BadCase 收集？优化后效果变化？）。
- **DAY6 全真模拟面试**：随机抽题每道 1-3 分钟掐时间；典型题：什么是 Agent / Agent 与普通工作流区别 / RAG 为何召回错误 / ToolCalling 失败怎么办 / Token 成本太高怎么办；答不上来记下来，回听逐句复盘（卡顿/超时/概念错）。
- **DAY7 只补漏洞不开新坑**：不再临时学 Multi-Agent 框架；把前 6 天问题重过一遍，检查 **4 件事**——八股能不能答、项目能不能讲、代码能不能写、方案能不能设计（概念·流程·追问 / 架构·难点·收益 / 手撕·调库·调试 / 选型·兜底·成本）。
