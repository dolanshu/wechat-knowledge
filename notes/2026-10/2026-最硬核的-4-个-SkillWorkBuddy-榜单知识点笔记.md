# 2026 最硬核的 4 个 Skill（WorkBuddy 榜单）知识点笔记

## 一句话总结
WorkBuddy 评出 2026 年最硬核的 4 个 Skill：**Composio**（连接器）、**Tavily**（AI 搜索）、**PlayWright-MCP**（网页执行）、**Self-Improving**（自进化）——分别补上 Agent 的"手、脚、底座、自我迭代"。

## 核心要点
| Skill | 类型 | 状态/评价 | 作用 |
|---|---|---|---|
| `Composio` 全能连接器 | 集成 | 已开源 / 极度火爆，集成 **800+** 外部工具 | 让 Agent 连上各种 SaaS/API，能力外延 |
| `Tavily Web Search` | AI 专用搜索 | 已开源 / 评价最高 | Skill 最稳的"底座"，给 Agent 可靠检索 |
| `PlayWright-MCP` | 网页执行官 | 已开源 / 动作类最强 | Agent 的"手和脚"，真正操作浏览器 |
| `Self-Improving` 自进化逻辑 | 自反思 | 部分开源 / 极具前瞻性 | 能自我反思和改进，越用越强 |

## 展开说明
- **定位互补**：Composio 解决"连得上"，Tavily 解决"搜得准"，PlayWright-MCP 解决"动得了"，Self-Improving 解决"长得快"。
- **选型建议**：前三个都已开源可直接装；Self-Improving 虽仅部分开源，但代表"Agent 自我迭代"的方向，值得关注。
