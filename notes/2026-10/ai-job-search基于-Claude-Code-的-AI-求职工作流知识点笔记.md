# ai-job-search：基于 Claude Code 的 AI 求职工作流（知识点笔记）

> 来源：微信视频号《把 Claude Code 变成你本地的求职工作流：ai-job-search，筛岗、改简历、面试押题全包》（HR 看了估计集体吐血，2 万星求职外挂开源）
> 提取方式：抽帧 → 画面 OCR → 整理
> 日期：2026-10-23

## 一句话总结
`ai-job-search`（GitHub ~21.3k stars）是一个**基于 Claude Code 构建的 AI 驱动职位申请框架**：填好资料 → 评估职位 → 定制简历/求职信 → 多平台搜岗去重并按匹配度排序 → 按 JD 逐岗定制、第二个 Agent 复核、面试模拟陪练。**不无人值守自动投递**，脏活累活全自动。

## 核心要点（工作流）
1. **填资料**：三种导入方式——`documents/` 文件夹（幂等，可重复添加）、直接上传简历文件、或手动输入；自动识别资料类型。
2. **评估职位**：让 Claude 评估职位发布。
3. **定制简历/求职信**：根据真实经历逐岗定制。
4. **找机会**：`/scrape` 多平台搜索符合简历的岗位、去重、按相关性呈现；岗位过多可用 `/rate` 批量评分排出优先级（5 个维度算匹配度）。
5. **申请**：`/apply <url>`（抓取不到则粘贴 JD）；选岗后吃透 JD、定制简历求职信，**再交第二个 Agent 复核**。
6. **面试**：根据 JD 出模拟题陪你演练。

## 展开说明
- **2026 成本拐点**：批量抓取去重 → 5 维度算匹配度 → 一口气排出最值得投的 JD 优先级。
- **边界**：明确"不会替你无人值守自动投递"；是独立开源项目，不隶属 Anthropic。
- **价值**：把"海投"的脏活（筛岗、改简历、面试押题）串成一条本地工作流，人只做最终决策。
