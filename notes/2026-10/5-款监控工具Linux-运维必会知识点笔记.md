# 5 款监控工具（Linux 运维必会）知识点笔记

> 来源：微信视频号《这 5 款监控工具都不会，还算什么 Linux 运维？》
> 提取方式：抽帧 → 画面 OCR → 整理
> 日期：2026-10-23

## 一句话总结
Linux 运维必会的 **5 款监控工具**：`Nagios`（主机/网络/设备状态监视）、`Grafana`（可视化出图）、`Prometheus`（监控+告警）、`Cacti`（流量/主机监控）、`Zabbix`（一键部署监控平台）——"这 5 款都不会，还算什么 Linux 运维"。

## 核心要点
| 工具 | 定位 |
|---|---|
| `Nagios` | 开源免费**网络监视工具**，有效监控 Windows/Linux/Unix 主机状态、交换机/路由器等网络设备、打印机等 |
| `Grafana` | 可视化面板（出图好看，弥补其他工具"出图不好看"的短板） |
| `Prometheus` | 监控 + 告警（有官方文档、操作指南） |
| `Cacti` | PHP 程序，**流量监控**工具更贴切，支持 Windows/Linux/Unix 主机、打印机 |
| `Zabbix` | 一小时轻松部署的监控平台 |

## 展开说明
- **组合使用**：Nagios/Cacti/Zabbix 负责采集与告警，Grafana 负责好看的可视化，Prometheus 负责现代云原生监控+告警。
- **学习资源**：视频附 Nagios 详细教程、Grafana 总结、Prometheus 操作指南、Cacti 中文手册、Zabbix 文档合集。
