# 简历没让人看到你能干活？测试开发面试实战（知识点笔记）

> 来源：微信视频号《简历没让人看到你能干活？》（测试开发 / 面试 / AI 测试）
> 提取方式：抽帧 → 画面 OCR → 整理
> 日期：2026-10-23

## 一句话总结
2026 招聘市场反差：**测试岗需求降 25%、AI 岗暴涨 24%**——降的不是"测试"，是只做执行。作者用"AI 测试提效平台"项目（独立全栈 + 7 步 Skill 编排把覆盖率从 20% 拉到 95%+）做简历亮点，复盘了 7 场 183 个提问里的高频面试题，最终拿到两个 offer。

## 核心要点
**1. 市场信号**：测试岗需求 −25%、AI 岗 +24%；"降的是只做执行的测试"，会 AI 提效的测试开发更吃香。

**2. 简历亮点项目：AI 测试提效平台（独立开发·全栈）**
- 技术栈：后端 Python + FastAPI + SQLModel + Alembic + SQLite；前端 Vue3 + Vite + TypeScript + Pinia + Vue Router。
- 核心能力：
  - ① **curl 反推接口文档**：以 curl 命令反向生成 Swagger 文档，解决存量系统"没有规范接口文档"的前置难题。
  - ② **7 步 Skill 链路编排**：需求分析 → 需求补充 → 测试点生成 → 测试点评审 → 测试用例生成 → 配置持久化 → 评审质检；测试点覆盖率由约 **20% 提升至 95% 以上**。
  - ③ 支持测试用例、接口自动化脚本、性能测试脚本三类生成。
- 提供在线演示地址（点开能看到的项目才是亮点）。

**3. 面试高频问题（7 场 183 提问归并）**——12 个主题被 3 场+问到、10 个被 2 场问到：
自我介绍 / 反问环节 / 期望薪资 / 到岗时间 / AI 提效平台是什么（与接口自动化脚本区别）/ 测试体系与团队建设 / 用 AI 遇过什么问题（幻觉怎么解决）/ 离职原因 / 需求质量怎么保证（没需求文档怎么办）/ 优势与短板 / 质量左移怎么落地（缺陷复盘机制）/ 覆盖率是多少（95% 的分母是什么）。
