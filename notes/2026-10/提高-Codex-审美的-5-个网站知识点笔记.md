# 提高 Codex 审美的 5 个网站（知识点笔记）

> 来源：微信视频号《提高Codex审美的5个网站》
> 提取方式：抽帧 → 画面 OCR → 整理
> 日期：2026-10-23

## 一句话总结
Codex 能写代码但缺审美，解决办法是让它**从优秀 UI 组件库里挑组件、对齐样式**，而不是裸写样式；视频给了 5 个直接可用的网站。

## 核心要点
1. **核心思路**：把"审美"交给成熟组件库——把组件库的链接发给 Codex，让它自己去找组件、改代码、统一项目视觉。
2. **5 个网站**：
   - `Beautiful UI`：AI 原生产品的组件，专门解决 Agent 怎么展示界面。
   - `beul`：精致的动画组件库。
   - `Rare UI`：小众、独特的视觉组件，用来制造"视觉亮点"。
   - `Transitions`：动效调优，给已有界面补上自然、专业的动画。
   - `shadcn/ui`：视觉统一、组件完整的 UI 组件库底座。

## 展开说明
- Codex 写界面"很容易但没啥审美"，瓶颈在样式与视觉一致性，而非逻辑。
- 用法：把上述网站链接贴给 Codex，让它去站点里自行选用组件、整合进项目，统一样式。
- 优先 `shadcn/ui` 打底（组件全、风格统一），需要差异化亮点时再叠加 `Rare UI` / `beul` / `Transitions`。
