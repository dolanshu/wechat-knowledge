## 一句话总结
Claude Code 官方语境下"最该装"的九大技能，覆盖**开发全流程**：从规划、TDD、代码审查，到 UI 设计、网页测试、长任务续跑、自定义技能与文档产出。

## 核心要点（九大技能）
| # | 技能 | 作用 |
|---|---|---|
| 1 | `Superpowers` | 内置 20 余种可组合技能，覆盖开发全流程，适配头脑风暴与 TDD |
| 2 | `Planning with Files` | 长任务上下文易截断，把规划方案持久化到文件、保留工程状态（大型项目刚需） |
| 3 | `CodeReview` | 代码自检、漏洞排查、规范校验（日常高频） |
| 4 | `UIUXProMax` | 内含 67 种设计风格 + 161 套配色，优化 AI 生硬审美，高效产出 UI/UX 方案 |
| 5 | `WebappTesting` | 基于 Playwright 的网页自动化测试：写脚本、跑测试、截图一站式 |
| 6 | `RalphLoop` | 解决 Claude 中途提前终止任务的痛点，长周期工程任务必备 |
| 7 | `SkillCreator` | 官方原生自定义技能工具，搭载 eval 测试框架，可自行开发专属技能 |
| 8 | `PPTX` | 项目汇报 / 需求文档 / 技术方案演示，工程交付常用 |

> 注：视频还把 UI/UX 类（UIUXProMax）在界面设计场景单独强调，与上述第 4 合并计为"九大"之一。
