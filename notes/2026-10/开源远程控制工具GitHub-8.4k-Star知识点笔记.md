# 开源远程控制工具（GitHub 8.4k Star）知识点笔记

> 来源：微信视频号《GitHub 8.4k Star 开源远程控制工具，手机/电脑互控，免费流畅的远程体验》
> 提取方式：抽帧 → 画面 OCR → 整理
> 日期：2026-10-23

## 一句话总结
一个 GitHub **8.4k Star** 的开源远程控制工具：跨平台（Windows/macOS/Android/Web），主控被控**互传文件、远程开机（WoL）、剪贴板同步、屏幕墙（单控/群控 100 台）**，基于定制 **WebRTC + Flutter + Vue3 + Nodejs**，免费流畅、二次开发无压力。

## 核心要点（功能）
- **互控矩阵**：web 网页 ↔ 电脑端 ↔ 安卓端 互相控制（web 端仅观看）；手机/电脑互控。
- **文件传输**：主控和被控互传文件。
- **远程开机**：支持 WoL 唤醒关机设备（需同网+外网两个条件）。
- **剪贴板同步**：主控/被控共享剪贴板。
- **屏幕墙**：查看/单控/群控设备，比连连控便宜 30%，支持 100 台（一行多列布局可调）。
- **驱动级键鼠**：避免游戏风控；鼠标模式（主控端/被控端/fps 游戏）。
- **连接鉴权**：自定义设备码/连接密码/中继服务器；多屏操作、多对一/一对多。

## 展开说明
- **技术栈**：定制 WebRTC + Flutter + Vue3 + Nodejs；硬件加速（NVIDIA/AMD H264/H265/AV1，驱动 570.0+）；主流编解码 H264/H265/AV1/VP8/VP9。
- **定位**：免费流畅的远程体验，跨平台，适合自建/二次开发（替代商业 TeamViewer/ToDesk 类）。
